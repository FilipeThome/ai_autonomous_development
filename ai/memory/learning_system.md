# Learning

When a review or a failure finds a repeated mistake, add one rule to `memory/memory.md` and one pattern to `memory/error_patterns.md`.

A rule is one sentence an agent can follow next time. Do not store a narrative.

Example: "Kotlin stays first-class beside Java and React; do not port Kotlin unless the user asks."

Stack-specific lessons belong in the matching skill under `.agents/skills/` only when they change how every future change in that stack should be done. Otherwise keep them in memory.
