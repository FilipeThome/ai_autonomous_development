# Diagnostics

1. Capture the exact failing command and the error text.
2. Find the first frame or log line that is causal, not the last wrapper.
3. State one root cause.
4. Fix that cause. Do not shotgun.
5. Re-run the failing command until it passes.

Follow `.agents/skills/diagnostics-self-heal/SKILL.md` for the regression test and the memory update.
